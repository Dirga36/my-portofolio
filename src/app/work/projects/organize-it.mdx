## Overview

OrganizeIt is a sleek, minimal Kanban-board web application designed to help individuals and small teams manage tasks efficiently. Built using Next.js and deployed on Vercel, it provides an intuitive visual interface to organize work items through progressive stages: To Do, Doing, and Done.

## Key Features

- **Kanban Workflow Management**: Interactive column layout allowing users to track task progress seamlessly across distinct stages (To Do, Doing, and Done).
- **Real-Time Task Tracking**: Dynamic task counter updates indicating active item status across all pipeline stages.
- **Responsive Visual Interface**: Clean typography and adaptive layouts designed for optimal usability on both desktop and mobile devices.
- **Fast Client Rendering**: Optimized performance powered by Next.js static asset optimization and web fonts.

## Technologies Used

- **Next.js**: Framework for building fast, server-rendered React applications.
- **React**: Library for creating dynamic and modular component architecture.
- **Tailwind CSS / Modern CSS**: For creating a responsive, accessible layout and visual polish.
- **Vercel**: Platform for continuous deployment and hosting.

## Challenges and Learnings

Creating a clean task management experience required balancing intuitive UX with minimal interface clutter. Implementing responsive board layouts that adapt seamlessly across devices while preserving fluid column organization was a major focus. The development process reinforced best practices in building structured component hierarchies and managing application state cleanly.

## Outcome

OrganizeIt provides a simple yet effective productivity workflow solution, helping users visually structure tasks and monitor progress efficiently in real time.
