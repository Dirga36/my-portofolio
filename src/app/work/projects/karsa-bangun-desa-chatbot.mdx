## Overview

Karsa — Bangun Desa Chatbot is an interactive web chatbot project built with TypeScript and deployed on Vercel. The project focuses on delivering an accessible and visually distinctive chat experience (Beige Glitch theme) for community-oriented interactions, information discovery, and simple conversational workflows. The public demo is available at the link above and the full source code is hosted on GitHub.

## Key Features

- Real-time chat UI with message history and user-friendly affordances
- Responsive UI, mobile-first layout
- TypeScript-first codebase for maintainability and type safety
- Lightweight state management sufficient for conversation flows
- Deployed to Vercel for instant previews and continuous deployment from the GitHub repo
- Simple developer experience: clone, install, run dev server

## Technologies Used

- Language: TypeScript (primary)
- Frontend framework: React (codebase uses TypeScript + React tooling)
- Styling: CSS / Tailwind (project includes CSS)
- Hosting / deployment: Vercel (live demo link)
- Tooling: Node, npm/yarn, common frontend dev tooling

## Architecture (high level)

- Client-side application
  - Chat UI composed of components for message list, input, and controls
  - Local state holds conversation history and UI state
- Integrations
  - (Optional) External APIs or serverless functions can be used to power replies or knowledge retrieval; check the repository for any API routes or function code
- Deployment
  - Hosted on Vercel for static/SSR builds and continuous deployment from the GitHub repository

## How it works (what to look for in the repo)

- Conversation handling
  - Messages are stored in component state (or lightweight store) and rendered in the chat view
  - Submissions trigger async handlers that call the bot logic (local or remote)
- UI behavior
  - Input includes accessibility considerations (labels, keyboard interactions)
  - Message list auto-scrolls on new messages
- Styling
  - The Beige Glitch visual style is applied via CSS and utility classes for consistent theming

## Running locally

Quick start (adjust if the project uses yarn or pnpm):

```bash
git clone https://github.com/Dirga36/karsa-bangun-desa-chatbot-beige-glitch.git
cd karsa-bangun-desa-chatbot-beige-glitch
npm install
npm run dev
# open http://localhost:3000 (or the port shown by the dev server)
```

If the repo includes a Vercel configuration or serverless functions, follow any additional setup steps in the repository README (API keys, environment variables).
