## Overview

Rasa Rumah (Rasa Rumah Cookies) is a dedicated web application for an artisanal home bakery that delivers handcrafted, freshly baked cookies made without preservatives. The platform addresses the need for a warm, visually engaging, and responsive digital storefront where customers can easily explore available fresh batches, dietary-specific selections (such as gluten-free cookies), and custom gift hampers.

Designed with a warm "Kejutan Rasa Rumah" home-baked aesthetic, the web app emphasizes product freshness by highlighting real-time stock limits per batch, detailed ingredient highlights, net weight options, and seamless direct-ordering workflows.

## Architecture (high level)

```markdown
- Client Application (Single Page Application)
  - Routes:
    - / -> Home / Landing Page (Hero, Value Propositions, Featured Items)
    - /katalog -> Full Catalog View with Filterable Categories
    - /hampers -> Dedicated Gift Packages & Hampers Customization
  - Navigation & UI Shell:
    - Shared layout with header navigation and footer component
    - Reusable card grid for dynamically rendering product items and stock tags

```

How it fits together: The client SPA uses component-based rendering powered by React and styled with Tailwind CSS. State handling manages active catalog filters and modal or navigation actions, providing fast client-side rendering without full page reloads.

## How it works (details worth noting)

* **Product Data Schema**
* Each item is modeled with attributes including ID, name, price, weight, description, stock remaining, badge indicators (`Favorit`, `Gluten free`), and imagery.


* **Visual Hierarchy & Branding**
* Styled around warm, inviting color tones that reflect a home-baked feeling while remaining clean and modern.


* **Responsive Grid System**
* Utilizes CSS Grid and Flexbox via Tailwind CSS to automatically scale product display grids from single-column on mobile to multi-column cards on larger screens.


* **Virtual Assistant**
* Built at top of integrated Lovable AI Gateway and using `google/gemini-2.5-flash` as the main AI model.

## Running locally

To set up and run the project on your local machine:

```bash
# Clone the repository
git clone https://github.com/Dirga36/rasa-rumah.git
cd rasa-rumah

# Install dependencies
npm install

# Start the development server
npm run dev

```

Open your browser and navigate to `http://localhost:8080` (or the port specified in the terminal).

## Challenges & learnings

* **Designing for Food E-Commerce**: Creating a layout where imagery, stock scarcity badges, and product descriptions harmonize without cluttering the screen.
* **Component Reusability**: Building modular card components that effortlessly handle varying badge counts (e.g., combinations of stock numbers, "Favorit", and "Gluten free").
* **Performance**: Optimizing high-resolution food imagery loading for fast initial page load times.

Rasa Rumah presents an inviting, high-converting digital storefront tailored for an artisanal home bakery. It provides customers with an intuitive browsing experience for fresh-batch handcrafted cookies and hampers while demonstrating modern React component architecture and Tailwind CSS design principles.
